# 产品需求文档 (PRD)
## Banana Pro - AI 图像编辑器

**版本：** 1.0
**日期：** 2025-01-01
**状态：** 待确认

---

## 一、项目概述

Banana Pro 是一个基于 AI 的图像编辑平台，用户可以通过自然语言描述来编辑图片。平台结合了先进的 AI 模型和直观的界面，让无需技术背景的用户也能实现专业级图像编辑。

**核心特色：**
- 用自然语言编辑图片（类似 ChatGPT 但针对图片）
- 出色的角色一致性保持能力
- 一次性编辑成功率
- 支持批量处理
- 多语言支持（中文、英文、日文）

## 二、功能需求

### 2.1 核心功能 (MVP)

#### 1. 模式切换
编辑器支持两种模式，通过选项卡切换：

**文生图模式：**
- 纯文字生成图片
- 只需输入提示词即可
- 无需上传参考图片
- 适用于从零开始创作

**图生图模式：**
- 图片编辑模式
- 需要上传参考图片
- 输入提示词描述编辑需求
- 适用于图片修改和优化

**切换交互：**
- 点击选项卡切换模式
- 切换时显示对应输入界面，隐藏另一种
- 淡入淡出动画过渡

#### 2. 图片上传（图生图模式专用）
- 支持拖拽上传
- 支持点击选择文件
- 支持格式：JPEG、PNG、WebP
- 文件大小限制：最大 10MB
- 图片分辨率：最高支持 4K
- 上传后显示预览，可更换/删除
- 支持多图选择（批量模式）

#### 3. 提示词编辑
- 文本输入框用于输入自然语言指令
- 字符限制：500 字符
- 提供示例提示词
- 保存最近 10 条历史提示词
- 支持复杂的多步骤指令

**文生图示例提示词：**
- "一只可爱的香蕉猫咪在月球上"
- "赛博朋克风格的未来城市，霓虹灯"
- "宁静的日本庭院，樱花飘落"

**图生图示例提示词：**
- "把这个人放到雪山背景中"
- "补全这张脸，让它看起来自然"
- "把背景改成热带海滩"
- "添加电影般的色彩效果"

#### 4. AI 图像生成
- 根据模式和输入生成对应结果
- 显示生成进度
- 目标生成时间：< 3 秒/张
- 支持批量处理（最多 4 张同时）
- 右侧实时展示生成结果
- 支持下载生成的图片

#### 5. 生成结果展示（右侧面板）
- 默认状态：显示占位提示文字
- 生成中：显示加载动画 + 进度百分比
- 生成完成：显示结果图片
- 支持图片点击放大查看
- 下方显示历史记录缩略图（最多4个）
- 历史缩略图点击可切换展示
- 操作按钮：
  - 下载：保存当前图片
  - 对比：原图 vs 生成图（仅图生图模式）
  - 重新生成：使用相同参数再次生成

#### 6. AI 模型选择
- 在编辑器顶部提供模型选择器
- 支持多个 AI 模型切换

**可选模型：**
- **Banana Pro V2**（默认推荐）- 最新模型，综合性能最佳
- **Banana Pro V1** - 稳定版本，速度快
- **Flux** - 适合艺术创作
- **Stable Diffusion** - 开源经典模型
- **DALL-E 3** - OpenAI 模型
- **Midjourney** - 高质量艺术风格

**模型切换交互：**
- 下拉选择或卡片式选择
- 显示每个模型的特点标签（如：速度、质量、风格）
- 切换模型后保留当前输入的提示词
- 显示当前使用的模型

#### 7. 高级选项（可折叠面板）
- 图片尺寸：512 / 768 / 1024 / 自定义
- 生成数量：1-4 张
- 风格预设：默认 / 动漫 / 写实 / 艺术 / 水彩
- 批量处理模式开关（专业版功能）

#### 8. 批量处理
- 批量模式开关
- 用同一提示词处理多张图片
- 显示处理队列
- 批量操作进度指示
- 可取消批量操作
- 打包下载所有结果（ZIP）

### 2.3 国际化 (i18n)

**支持 3 种语言：**
- 🇨🇳 中文（简体）
- 🇬🇧 英文
- 🇯🇵 日文

**实现要求：**
- 导航栏语言切换器
- 基于 URL 的语言路由 (/zh, /en, /ja)
- 翻译所有 UI 元素
- 翻译所有内容（功能介绍、评价、FAQ）
- 按区域格式化日期/数字
- 浏览器语言自动检测
- 允许手动切换语言

## 三、界面设计要求

### 3.1 设计原则
- 简洁、极简的界面
- 香蕉主题装饰元素（🍌）
- 现代、专业的美感
- 高对比度（符合 WCAG AA 无障碍标准）
- 响应式设计（手机、平板、桌面）
- 支持深色模式（可选）

### 3.2 视觉元素

**配色方案：**
- 主色：黄色/金色（香蕉主题）
- 次要色：黑色/深灰色
- 强调色：绿色（成功状态）
- 背景色：白色/浅灰色
- 文字色：深灰色/黑色

**字体：**
- 标题：粗体，无衬线
- 正文：常规，无衬线
- 提示词/代码：等宽字体

**图标：**
- 香蕉图标作为品牌标识
- 标准操作图标（上传、下载等）
- 功能专用图标
