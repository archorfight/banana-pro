### 2.1 AI API集成方案

**候选服务**:
1. **Replicate** - 推荐用于MVP
   - 优势: API简单，支持多种模型
   - 成本: 按使用付费
   - 模型: Flux, SDXL, Stable Diffusion

2. **Stability AI**
   - 优势: 官方API，稳定
   - 成本: 订阅制

3. **Together AI**
   - 优势: 开源模型聚合
   - 成本: 竞争力强

**技术实现**:
```typescript
// lib/api/image-generation.ts
export async function generateImage(params: {
  prompt: string;
  model: string;
  style: string;
  image?: string; // for img2img
}) {
  const response = await fetch('https://api.replicate.com/v1/predictions', {
    method: 'POST',
    headers: {
      'Authorization': `Token ${process.env.REPLICATE_API_TOKEN}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      version: MODEL_VERSIONS[params.model],
      input: {
        prompt: params.prompt,
        ...STYLE_PARAMS[params.style],
        image: params.image,
      },
    }),
  });
  return response.json();
}
```
