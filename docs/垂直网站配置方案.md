# Banana Pro 垂直网站快速上站方案

## 一、垂直网站架构设计

### 1.1 核心思路
- 共享核心代码库（Next.js + Monorepo）
- 每个垂直站独立配置（颜色、文案、SEO）
- 子域名隔离，便于独立运营和SEO
- 统一用户系统，数据互通

### 1.2 技术架构
```
banana-pro/
├── apps/
│   ├── main/              # 主站 - AI图像编辑器
│   ├── anime/             # 动漫风格站
│   ├── portrait/          # 肖像写实站
│   ├── cyberpunk/         # 赛博朋克站
│   └── prompts/           # 提示词宝库（现有）
├── packages/
│   ├── ui/                # 共享UI组件
│   ├── config/            # 共享配置
│   └── api/               # 共享API层
└── docs/
```

## 三、快速上站配置系统

### 3.1 配置文件结构

每个垂直站点只需一个配置文件即可快速生成：

```typescript
// apps/anime/config/site.config.ts
export const siteConfig = {
  // 基础信息
  name: "Anime AI Generator",
  description: "专注二次元AI绘画生成器，支持动漫角色、场景、风格生成",

  // SEO配置
  seo: {
    keywords: [
      "AI动漫生成",
      "anime AI generator",
      "二次元AI绘画",
      "动漫头像生成",
      // ...
    ],
    ogImage: "/og-anime.jpg",
    twitterCard: "summary_large_image",
  },

  // 主题配置
  theme: {
    primaryColor: "#FF6B9D",
    gradient: "from-pink-500 to-rose-500",
    fontFamily: "Anime",
  },

  // 功能配置
  features: {
    enabledModels: ["niji-journey", "anything-v5"],
    presets: animePresets,
    promptTemplates: animePromptTemplates,
  },

  // 导航配置
  navigation: [
    { label: "首页", href: "/" },
    { label: "动漫角色", href: "/characters" },
    { label: "动漫场景", href: "/scenes" },
    { label: "提示词库", href: "/prompts" },
    { label: "教程", href: "/tutorials" },
  ],

  // GA和分析
  analytics: {
    gtagId: "G-ANIME-XXX",
    ga4Id: "ANIME-GA4-XXX",
  },
};
```

## 四、SEO优化策略

### 4.1 每个垂直站的SEO结构

```
垂直站域名
├── 首页 (/)
│   ├── H1: 主关键词（如：AI动漫生成器）
│   ├── 2-3个核心关键词密度
│   └── Schema.org: SoftwareApplication
│
├── 功能页 (/features)
│   ├── 详细功能描述
│   └── 内链到具体功能页
│
├── 示例画廊 (/gallery)
│   ├── 大量用户生成图片
│   ├── 每张图带alt标签
│   └── 图片懒加载
│
├── 教程区 (/tutorials)
│   ├── 如何使用教程
│   ├── 提示词技巧
│   └── 案例分析
│
├── 博客 (/blog)
│   ├── 每周更新2-3篇
│   ├── 长尾词覆盖
│   └── 内链建设
│
└── 词汇表 (/glossary)
    ├── 行业术语解释
    └── 相关长尾词
```

### 4.2 Schema.org标记

每个页面添加结构化数据：

```json
{
  "@context": "https://schema.org",
  "@type": "SoftwareApplication",
  "name": "Anime AI Generator",
  "applicationCategory": "DesignApplication",
  "operatingSystem": "Web",
  "offers": {
    "@type": "Offer",
    "price": "0",
    "priceCurrency": "USD"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.8",
    "ratingCount": "1250"
  }
}
```

### 4.3 内容策略（按优先级）

**第1个月（启动期）**:
- 5个核心功能介绍页
- 10个使用教程
- 20个示例展示
- 完善FAQ

**第2-3个月（增长期）**:
- 每周2篇博客（长尾词）
- 每月1个专题页
- 用户生成内容（UGC）
- 社交媒体分享

**第4个月起（稳定期）**:
- 外链建设
- 合作伙伴互换
- 定期更新内容
- 数据驱动优化
