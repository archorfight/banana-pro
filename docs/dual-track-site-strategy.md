# 双轨并行做站规划

> 2026-07-29 | Archer

---

## 核心结论

两条路线同时跑，共享一套技术基建，但获客策略和节奏完全不同：

| 维度 | A轨：常青工具站 | B轨：趋势捕捉站 |
|---|---|---|
| 目标 | 长期 SEO 流量，3-6个月起量 | 短期爆发变现，1-2周回本 |
| 找词方式 | keyword-research-agent 八闸门 | 趋势监测（Twitter/Reddit/Google Trends） |
| 技术栈 | Next.js + Cloudflare Pages（静态） | banana-pro 技术栈复用（含 Auth+支付+积分） |
| 变现 | 免费→引流 / 后期加付费 | 信用积分制（免费试用→付费） |
| 上线速度 | 1-2 周 | 1-2 天 |
| 代表 | og-image-generator | kirkify 模式 |
| 风险 | 慢，可能 6 个月没流量 | 趋势退潮后收入归零 |

## B轨：趋势捕捉站（新增）

### B轨核心循环

```
发现趋势 → 判断是否可工具化 → 1天上站 → 快速SEO占位 → 变现 → 趋势退潮就撤
```

### Step 1：趋势发现（自动化）

**数据源：**
1. Google Trends 每日热搜（免费 API）
2. Reddit r/all 24小时热门（已有 RSS 源接入了素材库）
3. Twitter/X 热门 AI/meme 相关话题
4. Product Hunt 最新 AI 产品（看什么品类在爆发）

**判断标准（趋势→工具的可行性）：**
- [ ] 搜索词是动词/动作（"xxxify"、"make xxx"、"xxx generator"）→ 可工具化
- [ ] 趋势在上升期（Google Trends 斜率向上，但还没到峰值）
- [ ] 没有专门的工具站已经做了（或做得烂）
- [ ] 有明确的分享动机（用户做完会分享到社交媒体）
- [ ] API 成本可控（不需要 GPU 重计算，或用免费额度能撑住）

**反指标（不做）：**
- 纯信息类趋势（XX 去世了、XX 发布了）→ 没有工具意图
- 大厂马上会免费的（XX 的官方版本要出了）
- 合规风险高（deepfake 真人脸用于欺诈）

**自动化方案：**
创建一个 cron job，每天早上跑一次趋势扫描：
- 拉 Google Trends 前 20 热词
- 用 LLM 判断"是否可工具化 + 是否在上升期"
- 输出到飞书，Archer 人工决策做不做

### Step 2：快速上站（1天）

**关键：banana-pro 技术栈复用**

banana-pro 已经有完整基建：
- Next.js 14 前端
- Supabase Auth（登录注册）
- Creem 支付（含积分退款）
- Grasi 生图 API（可直接接 AI 图片类工具）
- i18n 国际化

**新趋势站只需要改 3 层：**

1. **前端皮肤层**（4小时）
   - 换品牌名、配色、文案
   - 核心 UI 组件（上传/输入/预览/下载）
   - 复用 banana-pro 的 layout 框架

2. **功能层**（4小时）
   - 趋势工具的核心功能（face swap / 图像生成 / 文字生成）
   - 接入对应 API（Replicate / Grasi / 其他）
   - 复用 banana-pro 的积分消耗逻辑

3. **SEO 矩阵层**（2小时）
   - 参照 kirkify 模式：品牌词 + 长尾变体
   - /what-is-[trend]、/how-to-[trend]、/[trend]-generator、/free-[trend]
   - 8-15 个页面，每个吃一个搜索意图

**部署：** Cloudflare Pages，当天上线。

### Step 3：快速 SEO 占位

**上线后立即做：**
1. 提交 sitemap 到 Google Search Console
2. Product Hunt 发布（kirkify 就这么做的）
3. "There's An AI For That" 提交收录
4. Reddit/X 发帖（带产品链接，蹭趋势热度）

**关键时间窗：** 趋势爆发的 1-2 周内，SERP 上还没有专门工具站，你的站能快速占位。kirkify 就是这么做的——在 "kirkify" meme 刚火的时候，他是唯一一个专门做这个的工具。

### Step 4：变现

**信用积分制（kirkify 模式）：**
- Free：1-3 次试用（有水印/排队）
- Bronze：$5-8 一次性（15次信用）
- Silver：$15/月（100次）
- Gold：$40/月（300次+视频）

**复用 banana-pro 的 Creem 支付 + 积分系统，不需要重新写。**

### Step 5：趋势退潮策略

- 监控 Google Trends + 收入数据
- 日收入降到峰值的 20% 以下 → 撤付费计划，站保留但不再维护
- 域名不续费（.xyz 一年才几块钱，沉没成本极低）
- 把技术栈模板和经验沉淀到下一个趋势站

## 诚实评估

**B轨的最大风险不是技术，是判断力。**
- 趋势抓早了：需求还没起来，做了没人搜
- 趋势抓晚了：SERP 已经被占，你进不去
- 趋势判断错：做了工具但没人愿意付费

kirkify 的教练能成功，大概率不是第一次就成——他可能试了多个趋势，kirkify 是跑通的那个。B轨需要有"快速试错、快速放弃"的心态，每个站投入控制在 1-2 天，不成就算了。

**B轨不适合作为唯一策略，但作为 A轨的补充，每周只需额外投入几小时，回报上限很高。**
