**交互说明：**

**模型选择：**
- 位于模式切换右侧，下拉选择器
- 默认选择「Banana Pro V2」并显示「推荐」标签
- 点击展开显示所有可用模型列表
- 每个模型显示：
  - 模型名称
  - 特点标签（如：⚡快速、🎨艺术、🔥热门、🆕最新）
  - 简短描述
- 切换模型后保留当前输入的提示词
- 当前选中的模型在选项卡后显示

**可选模型列表：**
| 模型名称 | 标签 | 描述 |
|---------|------|------|
| Banana Pro V2 | 🔥推荐 🆕最新 | 最新模型，综合性能最佳 |
| Banana Pro V1 | ⚡快速 | 稳定版本，速度快 |
| Flux | 🎨艺术 | 适合艺术创作 |
| Stable Diffusion | 📦开源 | 开源经典模型 |
| DALL-E 3 | 🌟知名 | OpenAI 模型 |
| Midjourney | 🖼️高质量 | 高质量艺术风格 |

**模式切换：**
- 点击「文生图」选项卡：显示文生图输入框，隐藏图生图上传区域
- 点击「图生图」选项卡：显示图片上传区域+提示词框，隐藏纯文生图提示词框
- 切换时有淡入淡出动画过渡

**文生图模式：**
- 只需输入提示词即可生成图片
- 提示词输入框支持多行输入（最多500字符）
- 提供示例提示词占位符
- "生成图片" 按钮需要：输入提示词
- 生成中显示进度动画
- 结果显示在右侧展示框

**图生图模式：**
- 左侧上传区域支持拖拽，拖入时高亮
- 上传后显示图片预览，可更换/删除
- 右侧提示词输入框描述编辑指令
- "生成" 按钮需要：已上传图片 + 输入提示词
- 生成中显示进度条/加载动画
- 结果显示在右侧展示框

**生成结果展示框（右侧）：**
- 默认状态：显示占位提示文字
- 生成中：显示加载动画 + 进度百分比
- 生成完成：显示结果图片
- 支持图片点击放大查看
- 下方显示历史记录缩略图（最多显示4个）
- 历史缩略图点击可切换展示
- 操作按钮：下载、对比（原图vs生成图）、重新生成

**高级选项：**
- 折叠面板，点击展开/收起
- 图片尺寸：下拉选择（512/768/1024/自定义）
- 生成数量：1-4张
- 风格预设：默认、动漫、写实、艺术等
- 批次模式开关（需要会员）

**批次模式交互：**

根据模式不同，批次模式有不同的表现：

**文生图模式的批次模式：**
- 本质就是"生成数量>1"，用同一提示词生成多张不同图片
- 高级选项中的"生成数量"就是批次控制
- 选择2-4张时，弹出升级提示（非会员）
- 会员用户可直接选择生成数量
- 生成按钮显示"生成 X 张图片"
- 结果区域显示网格视图展示所有生成的图片

**图生图模式的批次模式：**
- 批次模式区域始终可见，位于高级选项下方
- 显示 5 个上传占位符（"+"号网格）
- 默认状态：开关关闭，占位符显示为禁用状态（灰色）
- 点击开关弹出升级对话框（非会员）
- 会员用户可开启，开启后界面变化：
  - 开关变为黄色（开启状态）
  - 上传占位符激活（白色背景，可点击）
  - 支持多图选择（最多10张）
  - 显示已选图片列表（缩略图形式）
  - 每张图片可单独删除（显示×按钮）
  - 提示词对所有图片生效
  - 生成按钮显示"批量生成 X 张"
  - 生成中显示队列进度（1/10, 2/10...）
  - 结果区域显示网格视图（2x3或3x4）
  - "下载全部"按钮打包为ZIP
- 支持拖拽图片到任意占位符

**生成结果展示框（右侧）：**

根据选择的生成数量，结果展示框有两种模式：

**单张图片模式（生成数量 = 1）：**
- 大尺寸单图展示
- 默认状态：显示占位提示文字
- 生成中：显示加载动画 + 进度百分比
- 生成完成：显示结果图片
- 支持图片点击放大查看
- 下方显示历史记录缩略图（最多4个）
- 操作按钮：
  - 下载：下载当前图片
  - 对比：原图 vs 生成图（仅图生图模式）
  - 重新生成：使用相同参数再次生成

**多张图片模式（生成数量 > 1）：**
- 2x2 网格展示（最多4张）
- 顶部显示进度：已生成 / 总数（如 2/4）
- 每个格子显示生成状态：
  - 等待生成：灰色占位 + "等待生成..."
  - 生成中：加载动画
  - 生成完成：结果图片
- 生成按顺序进行，逐个完成
- 点击任意图片放大查看
- 操作按钮：
  - 下载当前：下载选中的图片
  - 下载全部：打包下载所有图片（ZIP）
  - 对比：原图 vs 生成图（仅图生图模式）
  - 重新生成：重新生成所有图片
- 历史记录缩略图显示在下方

**交互说明：**
- 切换生成数量时自动切换显示模式
- 选择 >1 需要会员，弹出升级提示
- 会员可直接选择 2-4 张
- 网格根据数量动态调整（2张、3张、4张）

- 触发场景：
  - 点击"批次模式"开关（非会员）
  - 点击"生成数量"超过1张（非会员）
  - 点击某些高级风格预设
- 升级对话框内容：

## 十、交互状态

### 按钮状态
- 默认：主色背景，白色文字
- 悬停：背景加深 10%
- 点击：轻微缩小
- 禁用：灰色背景，不可点击

### 输入框状态
- 默认：灰色边框
- 聚焦：主色边框 + 外发光
- 错误：红色边框 + 错误提示
- 成功：绿色边框

### 加载状态
- 按钮：显示旋转图标
- 区域：显示骨架屏
- 图片：显示模糊占位符
