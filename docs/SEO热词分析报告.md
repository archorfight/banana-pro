## 五、技术SEO要求

### 5.1 页面元数据模板

```typescript
// 基础SEO配置
const seoConfig = {
  // 首页
  home: {
    title: "{siteName} - AI图像生成器",
    description: "使用AI快速生成{style}风格图片，支持{features}",
    keywords: ["AI生成", "AI绘画", "{style} AI"],
  },

  // 功能页
  feature: {
    title: "{featureName} - {siteName}",
    description: "了解如何使用{featureName}生成{style}图片",
    keywords: ["{featureName}", "{style} AI", "AI生成器"],
  },

  // 画廊页
  gallery: {
    title: "{style} AI生成图片画廊",
    description: "浏览{count}张{style}风格AI生成图片，获取灵感",
    keywords: ["{style} gallery", "AI art examples", "{style} inspiration"],
  },

  // 博客页
  blog: {
    title: "{title} - {siteName} Blog",
    description: "{excerpt}",
    keywords: ["{primaryKeyword}", "{secondaryKeywords}"],
  },
};
```

### 5.2 Schema.org结构化数据

```json
// 软件应用
{
  "@type": "SoftwareApplication",
  "name": "{siteName}",

  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.8",
    "ratingCount": "1250"
  }

// 图片对象
{
  "@type": "ImageObject",
  "author": {
    "@type": "Person",
    "name": "{userName}"
  },
  "contentUrl": "{imageUrl}",
  "description": "{prompt}",
  "text": "{style} AI generated image"

// 如何操作
{
  "@type": "HowTo",
  "name": "{title}",
  "step": [
    {
      "@type": "HowToStep",
      "text": "{step1}"
    }
  ]
}
```
