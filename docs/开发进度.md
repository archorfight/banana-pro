## 二、已实现功能详情


## 四、已解决的技术问题

| 问题 | 解决方案 |
|-----|----------|
| Next.js不能在非空目录初始化 | 手动创建配置文件 |
| next-intl配置警告 | 创建 `i18n/request.ts` 并配置 next.config.js |
| notFound()在根布局报错 | 将locale参数处理移到 `app/[locale]/layout.tsx` |
| 消息键路径不匹配 | 统一消息结构为 `editor.models.*` |
| 端口被占用 | 使用taskkill清理端口 |
| Hydration错误（随机数） | 将随机点赞数改为固定初始值 |
